# Security

Report vulnerabilities through [GitHub's private vulnerability reporting](https://github.com/GillMacedo/wontexec/security/advisories/new), not in a public issue.

`wontexec` reads image archives and programs as data. It never runs, extracts to disk or loads anything it checks. Please report privately if a crafted image or binary could make it write files, run code, or use unbounded memory. A missed problem or a wrong finding is a normal bug.
